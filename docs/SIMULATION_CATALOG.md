# GradeNext Smart Lab — Simulation Catalog (Grades 1–12)

Companion to [SMART_LAB_PLAN.md](./SMART_LAB_PLAN.md). This is the content backbone: every planned simulation, organized by subject, with grade-band reach, modes, and build priority.

**How to read this catalog**

- **Grades** — the band(s) the sim serves. Many sims span bands via *adaptive depth* (one engine, K-2 → 9-12 skins), which is how ~150 sims cover thousands of curriculum touchpoints.
- **Modes** — 🧭 Explore · 🧪 Guided Lab(s) · 🎯 Challenge(s). Count of planned guided labs in parentheses.
- **Tier** — build priority: **T1** = MVP flagship set, **T2** = Phase 2, **T3** = Phase 3+.
